# Maliyet kaydı

Tarih: 14 Ekim 2026 (Europe/Istanbul). Planlama varsayımı: 30 odaklı saat / bir hafta. Bu gerçek personel timesheet'i değildir.

| Kalem | Gerçekleşen / gözlenen | Sınır |
|---|---|---|
| Yeni ücretli satın alma | Agent tarafından bu çalışma için 0 USD satın alma | Kullanıcının mevcut aboneliği bu sayıdan çıkarılmamıştır; toplam maliyet bilinmiyor |
| AI provider API | Uygulamada kullanılmadı | Kodlama agent'ının abonelik/token maliyeti ayrı |
| Token gideri | Oturumun kesin faturalama kaydı erişilebilir değil | Kesin sayı veya token USD tutarı uydurulmaz |
| Render | Hizmet oluşturulmadı; doğrulanmış fatura yok | Free-plan blueprint hazır; paid upgrade fiyatı satın alma sırasında doğrulanmalı |
| GitHub | Bağımsız repo oluşturuldu; public CI çalıştırıldı | Hesaba ait toplam Actions/billing faturası erişilmedi |
| Çalışma süresi | İlk local Git commit ile son commit zamanları Git log'dan denetlenebilir | Git zamanı toplam emek ölçüsü değildir |

Maliyet karşılaştırması: 30 saat bir planlama senaryosu, 0 USD yeni satın alma doğrulanmış eylem kaydıdır; bunlar aynı ölçüt değildir. Gerçek abonelik maliyeti için kullanıcı billing raporu gerekir.
